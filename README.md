# Анализ банковских транзакций

Проект для анализа финансовых операций из выгрузки банка. Позволяет получить статистику по расходам и доходам, а также информацию о курсах валют и акциях.

## Установка

1. Клонируй репозиторий:

git clone https://github.com/your-username/course-work-1.git
cd course-work-1
Установи зависимости:


poetry install
Помести файл с транзакциями в папку data/operations.xlsx

Использование
Запусти программу:


python src/main.py
Что выводится
Приветствие в зависимости от времени суток

Статистика по расходам и доходам

Топ-5 категорий расходов

Курсы валют (USD, EUR)

Цены акций из S&P 500

Запуск
bash
python src/main.py
Структура
src/main.py — главный файл

src/utils.py — чтение Excel

src/views.py — формирование отчёта

src/services.py — анализ кешбэка

src/reports.py — отчёты по категориям

tests/ — тесты
